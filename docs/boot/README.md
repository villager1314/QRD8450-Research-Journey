# Android 启动层研究

## 当前范围

研究启动链、A/B 分区、boot/vendor_boot、GKI 与模块关系，以及原厂 Android 和其他系统用户空间之间的兼容性。

已观察到的内核版本为 5.10.81，设备平台为 taro。曾尝试通过 DSU 启动其他 Android 系统，未形成稳定可用结果。具体镜像版本、日志和操作顺序尚待重新归档，暂不提供可复现刷机教程。
